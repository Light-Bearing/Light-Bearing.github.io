# light-bearing.github.io

Корень домена GitHub Pages. Здесь лежит только переадресация на страницу
телеграм-бота DropRadar:
**https://light-bearing.github.io/dropradar-site/**

Зачем: ссылку на проект получают партнёрские программы, и её вполне
могут обрезать до корня домена. До 13 сентября 2026 года корень отдавал
незаполненный бутстрап-шаблон 2017 года («Название фирмы или услуги…»).
Для страницы, по которой судят, настоящий ли проект, это худшее из
первых впечатлений.

Старый шаблон удалён из рабочего дерева, но **никуда не пропал**: он
лежит в истории репозитория, в коммите перед этим. Вернуть — `git
checkout <коммит> -- .`

Переадресация тройная и работает даже при выключенном JavaScript:
`<meta http-equiv="refresh">`, `location.replace` и видимая ссылка
«Открыть вручную». `canonical` указывает на целевую страницу, `noindex`
не даёт поисковикам держать в выдаче пустышку вместо неё.
